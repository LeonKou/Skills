# 工程规范基线（技术栈无关）

这是推荐起点，不得覆盖项目已确认规则。确定技术栈后，为每条规则补充适配版本和自动化验证。

## 必备原则

- `ARCH-001 REQUIRED`：模块边界单一职责，依赖方向由领域核心指向适配层。
- `CODE-001 REQUIRED`：命名表达业务语义，避免缩写；公共接口保持向后兼容。
- `CODE-002 REQUIRED`：输入在边界校验，错误显式返回并带稳定错误码。
- `DATA-001 REQUIRED`：所有结构变更可迁移、可回滚；事务边界写入蓝图。
- `API-001 REQUIRED`：接口包含版本、幂等策略、认证、超时和错误契约。
- `SEC-001 REQUIRED`：密钥只来自安全存储；日志脱敏，最小权限默认拒绝。
- `TEST-001 REQUIRED`：核心用例有自动化测试和可重复测试数据。
- `OBS-001 REQUIRED`：关键流程有结构化日志、指标、追踪和审计关联 ID。

每条项目规则使用 Skill 中定义的九字段结构，并明确例外和验证方式。
