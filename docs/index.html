01 / THE PROTOCOL

设计不是一次生成。
是逐步锁定。

01 — ASK

引导式提问

从目标、角色、用例到数据、架构与部署，按 15 个阶段拆解复杂度。

02 — CONFIRM

确认才算事实

严格区分事实、建议、假设和未决项。没有用户确认，不写入正式结论。

03 — SHIP

让智能体遵守

自动生成 AGENTS.md 与开发规范基线，让后续 Vibe Coding 有唯一真相源。

02 / THE OUTPUT

一份蓝图。
整个团队的共同内存。
